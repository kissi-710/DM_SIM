# 通常の時間で指した試合を、あとで時間をかけて検討しなおす(取りこぼしの調査)

実施: 2026-10-19(実験ブランチ `exp/replay-analysis`。main には入れていない)。

**問い**: CPU が通常の時間で指した試合を、あとで時間・反復を大幅に増やして検討しなおすと、「他に勝率の高い選択肢があったのに、時間内に選べなかった」ケースはあるか。ある場合、それを無くせるか。負けた試合は、どのタイミングで形勢が傾いたか。

生データは [data/ai-experiments-2026-10/replay/](./data/ai-experiments-2026-10/replay/)。全体の総括は [ai-strength-report.md](./ai-strength-report.md)。

## 1. 要約

1. **取りこぼしは存在する**。通常の探索の手と、深い再検討の手が食い違った判断を検証すると、深い探索の手が有意に良い判断が 14%、悪い判断が 4%(100 件)。有意に良い取りこぼしは、全判断の約 2.8%(1 試合あたり 1〜2 回。多重比較の補正をすると約 1.3 回)と見積もられる。
2. **取りこぼしの原因の一つは、早期終了**。通常の探索は、判断の 99.9% で早期終了し(反復の中央値 224 回、平均 39ms)、1200ms の制限をほぼ使わない。
3. **計算量を増やすと強くなる**。手を外す判定をなくし(`z=99`)、精度の基準を細かくした(`prec=0.003`)時間主導の探索が、通常の CPU に **56.8%**(960 試合、区間 53.6〜59.9%、+6.8pt)。1 手 675ms(通常の約 18 倍)。固定反復(3000、`z=99`)でも **54.3%**(1440 試合、区間 51.7〜56.9%)で、1 手 218〜267ms。
4. **ただし、大きな取りこぼしの多くは、計算量では直らない**。負けた試合で見つけた 8 件の取りこぼし(最善との差 15〜47pt)のうち、強い設定でも最善を選べたのは 1 件だけ(最善を選ぶ割合は 10〜12.5%)。残りは、**探索の見積もり(評価・プレイアウト)そのものが誤っている**ため、何度探索しても同じ誤った手を選ぶ。
5. **負けた試合の形勢**は、序盤の 30〜45% から徐々に下がり、5〜6 ターン目に一気に崩れる。大きく落ちる判断の多くは、勝った側の強い手や運。負けた側の自分の取りこぼしが決定的だった試合も、少なくとも 1 つある(試合9、ブロックしない判断。64% に対して 17%)。

## 2. 方法

1. **記録**: 通常の設定(`mcts:ms=1200`。アプリの既定と同じ時間主導)の CPU 同士で 80 試合(4 デッキの全 16 組を巡回、先攻後攻を交互)。手の列とシードを保存する。同じ手の列から、各判断の直前の局面を正確に再現できる。
2. **再検討**: 各判断(合法手が 2 つ以上、同じ意味の手を畳んで 2 つ以上)の局面で、深い探索(`mcts:iter=30000,z=99`。早期終了なし、全候補を最後まで評価。平均 2.2 秒)に選ばせ、実際の手と比べる。基準として、通常の探索を別の乱数でもう一度回した手(自分自身との食い違い)も記録する。
3. **検証**: 食い違った判断から無作為に 100 件を選び、実際の手と深い探索の手のそれぞれを指して、**あとを CPU 同士(`mcts:iter=80`)で最後まで 100 回プレイ**した時の勝率を比べる。教師の評価(L1 で続ける)は、不自然な結果を出したため使わない(ai-quality-plan §13)。
4. **追跡**: 負けた 8 試合(12〜16 ターン)で、各判断の直後の勝率(続きを 20 回プレイ)の推移を出し、負けた側の判断のうち勝率が大きく落ちた上位 3 件で、全候補の勝率(続きを 100 回)を測る。

## 3. 通常の探索の実態

(80 試合・5231 判断)

| 項目 | 値 |
|---|---|
| 1 判断の時間 | 平均 39ms / 中央値 12ms / 最大 1202ms |
| 反復回数 | 平均 487 / 中央値 224 / 上位 10% で 1024 |
| 早期終了(優劣が明確と判断) | **99.9%** |
| 1 試合あたりの判断 | 65.4(両者の合計) |

通常の探索は、設定した上限(1200ms)をほとんど使わない。早期終了の基準は、先頭と 2 位の差が「判定できる精度(2.5σ < 報酬の 1.2pt)」に達した時点(`pairedVerdict`)。

## 4. 深い探索との食い違い

| | 割合 |
|---|---|
| 実際の手 ≠ 深い探索の手 | 20.2% |
| 実際の手 ≠ 通常の探索の再実行の手(自分自身との食い違い) | 19.0% |
| 深い探索の手 ≠ 通常の探索の再実行の手 | 20.1% |

深い探索との食い違いは、通常の探索の自分自身との食い違いとほぼ同じで、食い違いの大半は、どちらを選んでもほぼ同じ「僅差」の判断のばらつき。

|---|---|---|---|
| マナチャージ | 867 | 23.2% | 24.2% |
| 攻撃に進む・ターン終了 | 652 | 4.6% | 4.8% |
| 召喚・詠唱 | 721 | 12.8% | 9.2% |
| 効果の選択 | 2499 | 25.4% | 23.2% |
| 攻撃 | 471 | 20.4% | 21.2% |

ターン帯別(自分のターン数): 1〜3 で 8.6%、4〜6 で 24.8%、7〜9 で 28.6%。

## 5. 食い違いの検証(続きの勝率)

食い違った 1053 判断から 100 件を無作為に選び、実際の手と深い探索の手のそれぞれを指して、あとを 100 回プレイした勝率を比べた。

| 結果 | 件数 |
|---|---|
| 深い探索の手が有意に良い(z ≥ 2) | **14** |
| 実際の手が有意に良い(z ≤ -2) | 4 |
| 差なし | 82 |

- 深い探索の手 − 実際の手の勝率差は、平均 **+3.1pt**(標準誤差 1.5)。
- 100 件の検定では、偶然に z ≥ 2 となるものが片側で 2〜3 件あるので、実際の取りこぼしは「14 − 4 ≒ 10 件」程度と見るのが保守的。全判断の約 2%、1 試合あたり約 1.3 回。補正なしの見積もりは約 2.8%、1.84 回。取りこぼしの勝率差は、有意なものの平均で 27pt。
- 通常の探索が、これらの判断でも早期終了していた(例: 試合15、5 ターン目。通常は 294ms・2618 反復で早期終了し、「攻撃: キーナリー → プレイヤー」(13%)を選んだが、「攻撃に進む(メインを終える)」(91%)の方が良かった)。

## 6. 負けた試合の追跡(8 試合)

負けた側から見た勝率の推移(ターンごとの平均)と、負けた側の判断のうち勝率が大きく落ちた上位 3 件の全候補の評価。続きの試行回数が少ない(推移は 20 回で、標準誤差約 11pt。全候補は 100 回で約 5pt)ので、小さな差は信頼できない。

| 試合 | 負けた側の勝率の推移 | 形勢が傾いた所 |
|---|---|---|
| 46(ザーディ 対 ロストマルル) | 31% → 2%(1〜6 ターン) | 4 ターン目から徐々に。5 ターン目に攻撃せずにターンを終え(3%)、攻撃すれば 21% |
| 38(ザーディ 対 インターステラ) | 35% → 0%(1〜7) | 2〜3 ターン目の召喚・マナチャージの取りこぼし(各 27pt・39pt) |
| 9(インターステラ 対 ザーディ) | 28% → 57%(5 ターン目)→ 6%(6) | 5 ターン目に勝った側が「手札に戻す」で 65pt 低下。負けた側の**ブロックしない**判断(17%)は、ブロックすれば 64% |
| 18(ザーディ 対 マルル) | 43% → 10%(1〜6) | 5 ターン目の攻撃(40pt 低下)、6 ターン目の選択(9% 対 最善 26%) |
| 51(ロストマルル 対 マルル) | 30% → 0%(1〜6) | 4 ターン目に勝った側の手で 60pt 低下 |
| 73(インターステラ 対 ザーディ) | 43% → 71%(4 ターン目)→ 7%(6) | 4〜5 ターン目に、オーパーツ銃の効果を**「使う」と選び続けた**(「使わない」の方が 7・19・7pt 高い) |
| 8(マルル 対 ザーディ) | 31% → 0%(1〜7) | 5 ターン目の召喚(アクアン 2% 対 フェアリー・ミラクル 17%) |
| 76(マルル 対 ロストマルル) | 43% → 3%(1〜6) | 5 ターン目に勝った側の手で 40pt 低下 |

- 8 試合中 2 試合(9・73)で、負けた側が途中に優勢(57%・71%)だった。他の 6 試合は、最初から 45% 以下で、徐々に下がった。
- 負けた側の取りこぼし(最善 − 実際 ≥ 12pt)は 8 件。そのうち大きいのは、試合9のブロック(47pt)、試合38のマナチャージ(39pt)、試合38の召喚(27pt)。
- 試合73では、同じカードの同じ「使うか」の選択で、3 回続けて、「使う」が選ばれ、「使わない」の方が良かった。これは、**評価の偏り**を示す繰り返しの癖。

## 7. 取りこぼしを減らす試み(対戦)

通常の CPU(`mcts:ms=1200`)と、複製対局(4 デッキの全 16 組)。区間は 95%。

| 設定(A) | A の勝ち(95% 区間) | 試合 | 1 手(A) | 内容 |
|---|---|---|---|---|
| `z=99,prec=0.003`(時間主導) | **56.8%**(53.6〜59.9) | 960 | 675ms | 手を外す判定なし + 精度の基準を細かく |
| `iter=3000,z=99`(seed 51 / 52) | 54.8%(50.3〜59.2)/ 54.1%(50.9〜57.2) | 480 / 960 | 218 / 267ms | 反復を固定、手を外す判定なし。**合計 1440 試合で 54.3%(51.7〜56.9)** |
| `iter=10000,z=99` | 54.6%(50.1〜59.0) | 480 | 708ms | 反復を増やしても、3000 と同じ(頭打ち) |
| `prec=0.003` | 53.3%(50.2〜56.5) | 960 | 118ms | 精度の基準を細かく |
| `iter=3000`(手を外す判定あり) | 53.3%(48.9〜57.8) | 480 | 73ms | |
| `z=99` | 52.7%(49.5〜55.8) | 960 | 192ms | 手を外す判定なし |
| `z=3.5,prec=0.003` | 52.2%(49.0〜55.3) | 960 | 229ms | |
| `prec=0.0015` | 51.8%(48.6〜54.9) | 960 | 149ms | |
| `iter=1000,z=99` | 51.5%(47.0〜55.9) | 480 | 75ms | |
| `z=3.5` | 50.7%(47.6〜53.9) | 960 | 57ms | 手を外す判定を慎重に |
| `minit=3000`(最低反復数) | 49.6%(46.4〜52.7) | 960 | 78ms | 1 位 2 位の判定による早期終了を、3000 反復まで禁止 |
| `minit=1500` | 48.2%(45.1〜51.4) | 960 | 60ms | |
| `iter=300,z=99` | 47.5%(43.1〜52.0) | 480 | 22ms | |

- **効くのは、手を外す判定をなくして(`z=99`)、全候補を十分に評価すること**。通常の約 6〜18 倍の時間をかけて +4〜7pt。反復 3000 で頭打ち。
- 早期終了の下限(`minit`)や、手を外す判定を慎重にするだけ(`z=3.5`)は、効かない。
- 通常(37〜44ms)の時間の枠で、安く取りこぼしを減らす設定は、見つからなかった。

## 8. 深い探索でも直らない取りこぼし

§6 の取りこぼし 8 件(最善との差 12pt 以上)で、強い設定の探索に、別の乱数で 5 回ずつ選ばせた。

| 設定 | 最善を選ぶ割合 | 実際と同じ手を選ぶ割合 |
|---|---|---|
| `iter=3000,z=99` | 10.0% | 60.0% |
| `ms=1200,z=99,prec=0.003` | 12.5% | 55.0% |

| 試合 | 判断 | 差 | 強い設定が最善を選ぶ(5 回中) |
|---|---|---|---|
| 46 | 攻撃せずターン終了 → 攻撃 | 18pt | 4 回 / 5 回(2 設定) |
| 38 | 召喚 → 攻撃に進む | 27pt | 0 / 0 |
| 38 | マナチャージ(オーパーツ銃 → フェアリー・ライフ) | 39pt | 0 / 0 |
| 9 | ブロックしない → ザーディクリカ 2 体でブロック | 47pt | 0 / 0(実際と同じ手を 5/5) |
| 18 | 効果の選択 | 17pt | 0 / 0 |
| 51 | 振り分け | 16pt | 0 / 0 |
| 73 | オーパーツ銃を使う → 使わない | 19pt | 0 / 0(実際と同じ手を 5/5) |
| 8 | 召喚 → フェアリー・ミラクル | 15pt | 0 / 0 |

**結論**: 大きな取りこぼしの多くは、**時間が足りないために起きるのではなく、探索の見積もりが間違っているために起きる**。深い探索も、同じ評価(3 ターン先 + 手作りの評価 + L1 のプレイアウト)で候補を並べるので、何度やっても同じ誤った手を選ぶ。これは、これまでの結果(計算量を増やしても頭打ち、評価の置き換えも効かない)と合う。

## 9. 結論と推奨

1. 「時間内に選べなかった」取りこぼしは、確かにある(約 1〜2 回 / 試合)が、強さへの影響は +4〜7pt の範囲。
2. 強くしたいなら、**「強い」設定として `z=99`(手を外す判定なし)+ 精度の基準を細かくした探索**をアプリの選択肢に加える案が、最も効果が大きい(+6.8pt)。1 手 0.2〜0.7 秒で、アプリの思考時間の上限(1.2 秒)に収まる。バッチ対戦では、時間が通常の約 18 倍になるので、使い分けが要る。
3. 時間をかけても直らない取りこぼし(ブロックしない、オーパーツ銃の効果を使う、など)は、**評価の改善**でしか直らない。たとえば、繰り返し出る癖(カード別の「使うか」の判断)を、データから学習する余地がある。これは、価値関数の学習(ai-quality-plan §6.3)や召喚の学習(§12)と同じ方向で、局面ごとの勝率を目標にする。

## 10. 限界

- 続きの勝率の測定は、続きを指す AI(`mcts:iter=80`)に依存し、通常の探索より弱い。検証は、その AI 同士で最後まで指した場合の勝率であり、実戦の勝率ではない。
- 追跡の試行回数は少ない(推移 20 回、全候補 100 回)。勝率の差が 10pt 未満の候補は、信頼できない。追跡の判断は、勝率が大きく落ちた上位 3 件だけ。
- 検証の 100 件は、食い違った判断の無作為抽出。偶然に有意になるものが含まれる(§5)。
- 80 試合・4 デッキのみ。別のデッキでは、傾向が変わる可能性がある。
- 続きのプレイは、手数の上限(検証 300 手、追跡 200 手)で打ち切り、引き分けとして数える。検証では 0%、追跡では未集計。

## 11. 再現

```bash
# 1. 通常の時間で 80 試合を記録し、深く再検討(約 30 分)
npx tsx scripts/replay-run.ts collect main80 80 5
npx tsx scripts/replay-run.ts deep main80
# 2. 食い違いを、続きの勝率で検証(約 20 分)
npx tsx scripts/replay-run.ts verify main80 100 100 mcts:iter=80 1
npx tsx scripts/replay-run.ts report main80
# 3. 負けた試合の追跡(約 40 分)と、強い設定が取りこぼしを選べるか
DM_CONT_CAP=200 npx tsx scripts/replay-run.ts trace main80 8 20 100 mcts:iter=80 3 12 16
npx tsx scripts/replay-run.ts report main80 trace
npx tsx scripts/replay-run.ts strongtrace main80 "mcts:iter=3000,z=99" 5 0.12
# 4. 対戦での比較(例: 強い設定 対 通常)
npx tsx scripts/history-bench.ts --a cur --aextra z=99,prec=0.003 --b cur --mode time --n 1200 --games 30 --seed 71
npx tsx scripts/history-bench.ts --a cur --aspec "mcts:iter=3000,z=99" --b cur --bspec "mcts:ms=1200" --games 30 --seed 52
```

設定の追加: `prec=<精度>`(近い手の比較を打ち切る精度。既定 0.012)、`minit=<反復数>`(1 位 2 位の判定による早期終了をしない下限)、`z=<数>`(手を外す判定の厳しさ。99 で外さない)、`chh=<ターン数>`(マナチャージだけの先読み)。
