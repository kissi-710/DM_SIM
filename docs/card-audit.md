## 見つけた誤りの記録

(監査で見つけたものを、ここに 1 行ずつ足す: デッキ・カード・何が違ったか・直し方。)

- **D-1 卍 新世壊 卍**: 「置く」は強制、「引く」だけ任意になっていた。公式Q&A(2021.10.22。二次出典: dmwiki)では、**置き換えること自体が任意で、置いたら必ず引く**。エンジンも、`afterCast` の置換の `optional` を無視していたので、聞くようにした(TS・Rust)。
- **D-2 好詠音愛 クロカミ**: 「コストは0以下にはならない」の下限(`floor: 1`)が無かった。
- **D-3 堕呪 ボックドゥ**: P能力(テキストの先頭)を、通常の効果のあとに処理していた。先頭に直した。
- **E-1 コスト軽減の下限(エンジン・複数のデッキ)**: 「ただしコストは0以下にはならない」を持つのに下限(コスト1)が無かった = キリモミ・ヤマアラシ・T・T・T(E。`nextSummon`)、ハイパーエナジー(エンジン。GENJI・ハイパーXX・ストーム・ハイパーXX・爆翠月 アカネ・オルゲイト)、アシスター・コッピ・チャラ・ルピア(G)、クロカミ(D-2)。下限は、軽減が働いた時だけ(元のコストが 0 なら 0 のまま。公式Q&A 40363)。TS・Rust とも直した。支払うマナの枚数は(文明の数で)変わらないが、コストが 0 になる扱いは誤り。
- **I-1 アシスター・Mogi林檎**: 「ただしコストは0以下にならない」の下限(`floor: 1`)が無かった。
- **I-2 瞬閃と疾駆と双撃の決断**: 「コスト3以下のクリーチャーを1体、自分の手札から出す」が、0体で済ませられる選択(selectUpTo)だった。強制の選択に直した(E-3 と同じ)。
- **J-1 永遠のリュウセイ・カイザー / ボルシャック・フレア(エンジン)**: 「(相手の)クリーチャーはタップして出る」「各ターン、はじめて出る相手のクリーチャーは、タップして出る」が、クリーチャー以外(フィールド・タマシードなど)にも当たっていた。「はじめて」も、クリーチャーの数で数えるようにした(TS・Rust)。
- **J-2 斬龍電融 オロチリュウセイ**: 「自分のターン中、自分の山札の上から1枚をいつでも見てもよい」が未実装だった(情報だけの能力)。常在型能力 `peekDeckTop` を足し、PlayerView が山札の一番上を開くようにし(AI の決定化にも伝わる)、盤面の山札の横に名前を出す。
- **M-1 アビスベル=ジャシン帝**: 「墓地にあるクリーチャーの召喚コストを2少なくする。ただしコストは0以下にならない」の下限が無かった。
- **M-2 深淵の壊炉 マーダン=ロウ**: 「相手の手札を見てクリーチャーを1体選び、捨てさせる」が、0体でも済ませられる選択だった。強制の選択に直した。
- **M-3 邪幽 ジャガイスト**: 手札が2枚に満たなくても「手札を2枚捨ててもよい」を聞いていた(1枚だけ捨ててメクレイドできた)。手札が2枚ある時だけ使えるようにした。
- **N-1 ヘルトッQ**: 「出たターンに相手プレイヤーを攻撃できる」を、スピードアタッカーにしていた(出たターンに、タップしたクリーチャーも攻撃できてしまう)。常在型能力 `attackPlayerOnEntry`(プレイヤーだけ攻撃できる)を足した(TS・Rust)。
- **N-2 めっちゃ! デンヂャラスG3**: 「自分のクリーチャー3体に」が「3体まで」の選択だった(ちょうど3体。足りなければ全員)。
- **N-3 ケッシング・ゼロ(エンジン)**: 「相手のクリーチャーすべての能力を無視する」が、フィールド・クロスギアなど、クリーチャー以外にも当たっていた。クリーチャーだけにした(TS・Rust)。
- **O-1 ジョーカーズの心絵**: 「山札に加えたカード1枚につき」を、クリーチャー・タマシードの数で数えていた(進化元など、重なっていたカードが数えられない)。`shuffleIn` が、山札に加わった枚数を変数に入れる(`as`)ようにし、その枚数だけシールド化する(TS・Rust)。
- **Q-1 五番龍 レイクポーチャー**: 「同じコストの相手のクリーチャーを1体選び、手札に戻す」が、選ばなくても済む選択だった。強制に直した。
- **R-1 ヴァルキリアス・武者・ムサシ「弐天」**: 「破壊する」(相手のエレメント1つを選ぶ)が、選ばなくても済む選択だった。強制に直した。
- **T-1 スターゲイズ・ゲート**: 「出す」(「出してもよい」ではない)が、出さなくても済む選択だった。強制に直した。
- **U-1 全虹帝 ミノガミ**: 「ツインパクトカードを1枚、墓地からマナゾーンに置く」が、置かなくても済む選択だった。強制に直した。
- **U-2 五輪の求道者 清永**: 「残りをすべてマナゾーンに置く」は独立した文なので、コストがすべて異ならなかった時も、3枚ともマナゾーンに置く(二次出典: dmwiki の注釈。公式の裁定は未確認)。以前は、何も起きなかった。
- **V-1 轟轟轟ブランド**: 「手札を捨てた1枚につき、相手のクリーチャーを1体選び、破壊する」が、捨てた枚数より少なく選べる選択だった(ちょうどその数。足りなければ全員)。
- **V-2 弾丸超邪 クロスファイア・「みんな一緒に応援してね!」**: 「1体に与える」「選び、破壊する」が、選ばなくても済む選択だった。強制に直した。
- **V-3 清浄のカルマ インカ**: 「相手のクリーチャーは、相手の手札以外から出ない」が、クリーチャー以外(フィールド・タマシードなど)にも当たっていた。クリーチャーだけにした。
- **W-1 侵略(エンジン・K02/W03/W04/W08)**: 通常の「侵略」も、墓地・マナゾーン・バトルゾーンのカードから重なれた。通常の侵略は**手札からだけ**にし、S級侵略(禁断の轟速 ブラックゾーン)は手札・墓地・バトルゾーン(公式の説明。二次出典: dmwiki)、SSS級侵略(デッドダムド)は手札・マナ・墓地・バトルゾーンにした(`invasion` の `from`)。
- **W-2 再興王女プリン**: 「エイリアン・クリーチャーを1体、超次元ゾーンから出す」が、出さなくても済む選択だった。強制に直した。
- **X-1 超神星DOOM・ドラゲリオン**: メテオバーンの「進化ではないクリーチャーを1体、墓地から出す」が、出さなくても済む選択だった。強制に直した。
- **Y-1 神羅ケンジ・キングダム**: 「その3枚の中からクリーチャーを1体出す」が、出さなくても済む選択だった。強制に直した。
- **P-1 水上第九院 シャコガイル(エンジン)**: 「最後の1枚を引いたことによって負ける時、かわりに勝つ」が、山札が0枚になった原因を問わず(墓地に置かれて0枚の時も)働いていた。山札から最後に離れたのが「引く」だった時だけにした(`gameLoss` の `reason: 'deckOutDraw'`。TS・Rust)。
- **R-2 竜装 ザンゲキ・マッハアーマー / 竜牙 リュウジン・ドスファング(エンジン)**: 「このクロスギアをコストを支払わずに〜にクロスしてもよい」を、ジェネレートした時の1回の誘発にしていた。実際は、あとからでも、いつでもコストを支払わずにクロスできる。常在型能力 `freeCrossTo`(その相手には、マナを払わずにクロスできる)にした(TS・Rust)。
- **P-2 環嵐! ホールインワン・ヘラクレス(エンジン)**: 「タマシード/クリーチャー」で、自分の自然のクリーチャーまたは自然のタマシードが合計4つ未満の間は、クリーチャーとして扱わない。常にクリーチャーとして扱い、攻撃だけ禁じていた(クリーチャーを選ぶ効果の対象になる)。面の `tamaseedUnless`(バトルゾーンでは、この条件を満たさない間、タマシードとして扱う)を足し、種類の問い合わせすべてに反映した(TS・Rust)。
- **注意(監査の見落とし防止)**: 下限の文言は「0以下には**なら**ない」(「は」なし)もある(真久間メガ・Mogi林檎・ボルシャック・ガラワルド・「必然」の頂 リュウセイ・アビスベル=ジャシン帝・ドラゲリオン)。J・L・M・X の監査で下限の有無を確かめる。
- **E-2 最期の竜炎**: 手札がなく何も捨てられない時、「こうして捨てたカード」が無いのに、コスト0以下の相手のエレメントを選べた。捨てられた時だけ選ぶようにした。
- **E-3 氷柱と炎弧の決断**: 「コスト2以下のエレメントを1つ、手札から出す」(「出してもよい」ではない)が、0 体で済ませられる選択(selectUpTo)になっていた。強制の選択に直した。
