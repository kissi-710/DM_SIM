## 3. カード詳細(効果の要約)

表記: 🔹=キーワード能力 / ▶=誘発型・効果 / 🔸=常在型・置換型。「任意」は「〜してもよい」の能力。

### 3.1 マルルデッキ(A)

**A1 フェアリー・ライフ**(呪文 / 2 / 自然)
- 🔹S・トリガー
- ▶山札の上1枚をマナゾーンに置く。

**A2 フェアリー・Re:ライフ**(呪文 / 2 / 自然)
- 🔹G・ストライク: シールドゾーンから手札に加える時、相手に見せれば、相手のクリーチャー1体を選び、そのターン中攻撃できなくしてもよい。
- ▶山札の上1枚をマナゾーンに置く。(S・トリガーは持たない)

**A3 蒼狼の豊穣 ワクムテラス / オリジナル・ライフ**(ツインパクト)
- クリーチャー面(4 / 水): ▶出た時、カードを2枚引く。
- 呪文面「オリジナル・ライフ」(2 / 自然): ▶山札の上1枚をマナゾーンに置く。

**A4 / B2 天災 デドダム**(クリーチャー / 3 / 水・闇・自然 / パワー3000 / トリニティ・コマンド・侵略者)
- ▶出た時、山札の上から3枚を見る。1枚を手札、別の1枚をマナゾーン、残りの1枚を墓地に置く(強制)。

**A5 ヨビニオン・マルル**(クリーチャー / 4 / 自然 / 5000 / スノーフェアリー)
- ▶ヨビニオン: 召喚によって出た時、山札の上から、このクリーチャーよりコストが小さいクリーチャーが出るまでカードを表向きにしてもよい。そのクリーチャーを出し、残りをシャッフルして山札の下に置く。
- ▶各ターン、自分の**2体目**のクリーチャーが出た時、山札の上1枚を見て、手札に加えるか、タップしてマナゾーンに置く(強制)。

**A6 ヨビニオン・トライブ**(クリーチャー / 4 / 自然 / 4000 / ビーストフォーク)
- 🔹このクリーチャーを自分のマナゾーンから召喚してもよい。
- ▶ヨビニオン(A5と同じ。基準はこのカードのコスト4)。
- 🔸このクリーチャーが破壊される時、墓地に置くかわりにマナゾーンに置く(置換効果・強制)。

**A7 ティンパニ=シンバリー**(クリーチャー / 4 / 闇 / 4000 / アビスロイヤル)
- 🔹ブロッカー
- ▶ヨビニオン(基準はコスト4)。
- ▶各ターン、自分の2体目のクリーチャーが出た時、このクリーチャーを破壊してもよい。そうした場合、相手は自身のクリーチャーを1体選んで破壊する。

**A8 修羅の死神フミシュナ / 「この先は修羅の道ぞ」**(ツインパクト)
- クリーチャー面(4 / 闇 / 4000 / デーモン・コマンド):
  - 🔹ブロッカー
  - ▶出た時、相手の手札を1枚見ずに選び、捨てさせる。
  - ▶相手が自分の手札を捨てた時、1ターンに1回、カードを1枚引いてもよい。
- 呪文面(5 / 水): 🔹S・トリガー / ▶次の2つから**2回**選ぶ(同じものを2回でも可): カードを1枚引く / 相手のクリーチャー1体を持ち主の手札に戻す。

**A9 絶望と反魂と滅殺の決断**(呪文 / 5 / 闇)
- 🔸この呪文は自分の墓地から唱えてもよい。その場合、唱えた後は墓地に置かず山札の下に置く。
- ▶次の3つから**2回**選ぶ(同じものを2回でも可):
  1. 相手は自分の手札を1枚選んで捨てる。
  2. 自分の墓地から、コスト4以下の闇のクリーチャー1体、またはコスト4以下の闇のオーラ1枚を出す。
  3. 相手のクリーチャー1体を選ぶ。このターン、そのパワーを-4000する(パワー0以下は破壊される)。

**A10 流星のガイアッシュ・カイザー**(クリーチャー / 6 / 水・自然 / 8000 / ブルー・コマンド・ドラゴン・グリーン・コマンド・ドラゴン・ハンター)
- 🔹W・ブレイカー
- ▶出た時、カードを2枚引く。
- 🔸自分のコスト10以上のクリーチャーを召喚するコストが4少なくなる(0未満にはならない)。
- 🔸相手のクリーチャーは、出たターンに自分(プレイヤー)を攻撃できない。
- ▶相手のターン終了時、相手がそのターン中に**マナをタップせずに**呪文を唱えた、またはクリーチャーを出した場合で、自分のバトルゾーンにこのカードがなければ、コストを支払わずに召喚してもよい。

**A11 CRYMAX ジャオウガ**(S-MAX進化クリーチャー / 7 / 闇 / 13000 / デモニオ・鬼レクスターズ)
- 🔹鬼S-MAX進化: 進化元を必要としない。自分が**ゲームに負ける時**、またはこのクリーチャーが**離れる時**、かわりに自分の表向きのカード3枚を破壊してもよい。自分のS-MAX進化クリーチャーが2体以上いる場合、1体を残して残りを手札に戻す。
- 🔹T・ブレイカー
- ▶出た時、各プレイヤーは自分のシールドゾーンから3枚を選び、残りを墓地に置く。
- ▶攻撃する時、相手のクリーチャー1体を選んで破壊し、その後、相手の手札を2枚見ずに選んで捨てさせる。

**A12 魔誕の斬将オルゲイト**(クリーチャー / 7 / 水 / 7000 / デーモン・コマンド)
- 🔹ハイパーエナジー: 召喚する時、バトルゾーンの自分のクリーチャーを**コストが互いに異なる**ように好きな数タップできる。タップした1体につき、召喚コストが2少なくなる(0未満にはならない)。
- 🔹ブロッカー / 🔹W・ブレイカー
- 🔹ジャストダイバー: 出た時、次の自分のターンのはじめまで、相手に選ばれず、攻撃されない。
- ▶出た時、相手のクリーチャー1体を選び、持ち主の手札に戻してもよい。
- ▶**相手のターン中**に相手のクリーチャーが出てその能力がトリガーした時、自分もその能力を使ってもよい(能力の処理はオルゲイト自身が行う)。

**A13 終末の監視者 ジ・ウォッチ**(クリーチャー / 10 / 水 / 12000 / アウトレイジMAX)
- 🔹T・ブレイカー
- ▶召喚によって出た時、または攻撃する時、クリーチャーを2体まで選び、持ち主の手札に戻す。
- ▶相手のクリーチャーが出た時、または相手が呪文を唱えた時、ターンの残りをとばしてもよい。

**A14 逆転の剣スカイソード**(クリーチャー / 10 / 自然 / 5000 / ビーストフォーク)
- 🔹S・トリガー
- ▶出た時、相手のクリーチャー1体を選び、持ち主のマナゾーンに置いてもよい。その後、**自分のマナゾーンのカードの枚数より小さいコスト**のクリーチャーを1体、自分のマナゾーンから出してもよい。

**A15 終末縫合王 ザ=キラー・キーナリー**(クリーチャー / 10 / 水・闇・自然 / 15000 / ディスペクター・ジュラシック・コマンド・ドラゴン・ドラゴン・ゾンビ)
- 🔹EXライフ(出る時、山札の上1枚をシールドにする。離れる時、かわりにそのシールドを墓地に置く)
- 🔹T・ブレイカー
- ▶出た時、相手のクリーチャー1体を選び、持ち主の手札に戻してもよい。その後、**選んだクリーチャーのコスト以下**のクリーチャーを1体、自分の墓地から出す(戻したかどうかに関係なく、選んだクリーチャーのコストで判定)。
- 🔸相手のクリーチャーが出てその能力がトリガーする時、かわりにその能力はトリガーしない。

**A16 九番龍 ジゴクバンカー Par459**(クリーチャー / 12 / 自然 / 10000 / ジャイアント・ドラゴン)
- 🔹シンパシー: 自分のマナゾーンのカード1枚につき、召喚コストが1少なくなる(0未満にはならない)。
- 🔹マッハファイター: 出たターンに、相手のクリーチャーを(タップ・アンタップを問わず)攻撃できる。プレイヤーは攻撃できない。
- 🔹W・ブレイカー
- ▶出た時、山札の上1枚をマナゾーンに置く。その後、自分のマナゾーンからカード1枚を手札に戻してもよい。

### 3.2 5cザーディデッキ(B)

**B1 フェアリー・ミラクル**(呪文 / 3 / 自然)
- ▶山札の上1枚をマナゾーンに置く。その後、自分のマナゾーンに**すべての文明**がそろっていれば、さらにもう1枚、山札の上からマナゾーンに置く。(最初のブーストは無条件。5文明の確認はそのあと。)

**B3 アクアン**(クリーチャー / 4 / 水 / 2000 / サイバーロード)
- ▶出た時、山札の上から5枚を表向きにしてもよい。そのうち光のカードと闇のカードをすべて手札に加え、残りを墓地に置く。

**B4 王道の革命 ドギラゴン**(クリーチャー / 5 / 光・火・自然 / 5000+ / メガ・コマンド・ドラゴン・革命軍)
- 🔹ブロッカー / 🔹スピードアタッカー
- ▶出た時、山札の上2枚をマナゾーンに置く。その後、クリーチャーを1体、自分のマナゾーンから手札に戻す。
- 🔸革命2: 自分のシールドが2つ以下なら、シールドゾーンから手札に加えるこのクリーチャーに「S・トリガー」を与える(シールド枚数はブレイク後に数える)。
- 🔸革命0: 自分のシールドが1つもなければ、バトル中パワーが+10000され、バトルに勝った時にアンタップする。

**B5 漢気の2号 ボスカツ**(クリーチャー / 5 / 光・闇・火 / 4000 / メガ・コマンド・ドラゴン・革命軍・ハムカツ団)
- 🔹スピードアタッカー
- ▶出た時、相手の手札を1枚見ずに選び、捨てさせる。その後、**捨てさせたカードと同じ文明**を持つ、コスト8以下の多色クリーチャーを自分の手札から出してもよい。(マッドネスで捨てが置き換わった場合は、文明がなく何も出せない。)

**B6 魔誕と光喜と楽識と炎怒と哀樹の決断**(呪文 / 5 / 光・水・闇・火・自然)
- ▶次の5つから**2回**選ぶ(同じものを2回でも可):
  1. 自分の山札の上1枚をシールドにする。
  2. カードを2枚引く。
  3. 相手の手札を1枚見ずに選び、捨てさせる。
  4. 相手のコスト6以下のエレメントを1つ選び、破壊する。
  5. 山札の上1枚をマナゾーンに置く。その後、マナゾーンからカード1枚を手札に戻してもよい。
- 🔸自分のエレメントに**すべての文明**がそろっていれば、2回選ぶかわりに、5つすべてを1回ずつ使ってもよい。

**B7 ドラゴンズ・サイン**(呪文 / 5 / 光)
- 🔹S・トリガー
- ▶自分の手札から、光のドラゴンで進化ではないコスト7以下のクリーチャーを1体出す。そのクリーチャーは、次の自分のターンのはじめまでブロッカーを得る。

**B8 ドンドン火噴くナウ**(呪文 / 5 / 水・火・自然)
- 🔹S・トリガー
- ▶山札の上3枚を見る。1枚をマナゾーン、1枚を手札、残りの1枚を墓地に置く。こうして墓地に置いたカードの**コスト以下**の相手のクリーチャー1体を選び、破壊する。

**B9 ブレイン・スラッシュ**(呪文 / 6 / 水・闇)
- 🔹S・トリガー
- ▶次のいずれか1つを選ぶ: ①カードを3枚引き、その後自分の手札を1枚捨てる / ②コスト8以下のクリーチャーを1体、自分の墓地から出す。
- 🔸自分のクリーチャー(またはタマシード)に水と闇がそろっていれば、両方を選んでもよい(上から順に処理)。

**B10 龍風混成 ザーディクリカ**(クリーチャー / 7 / 光・水・火 / 6000 / ディスペクター・クリスタル・コマンド・ドラゴン・エンジェル・コマンド・メルト・ウォリアー)
- 🔹EXライフ / 🔹W・ブレイカー
- ▶出た時、コスト7以下の呪文を1枚、自分の手札または墓地からコストを支払わずに唱えてもよい。唱えた後は墓地に置かず、山札の下に置く。
- ▶自分のターン終了時、そのターンに自分が呪文を唱えていれば、相手のパワー5500以下のクリーチャーを1体破壊し、その後カードを1枚引いてもよい。

**B11 ロスト・Re:ソウル**(呪文 / 7 / 闇)
- 🔹G・ストライク(A2と同じ)
- ▶相手は自分の手札をすべて捨てる。

**B12 聖魔連結王 ドルファディロム**(クリーチャー / 8 / 光・闇・火 / 13500 / ディスペクター・エンジェル・コマンド・デーモン・コマンド)
- 🔹EXライフ / 🔹スピードアタッカー / 🔹T・ブレイカー
- ▶このクリーチャーが出た時、または**EXライフのシールドが自分のシールドゾーンを離れた時**、相手の多色でないクリーチャーをすべて破壊する。
- 🔸相手は、多色でない呪文を唱えられない。

**B13 SSS級天災 デッドダムド**(進化クリーチャー / 8 / 水・闇・自然 / 11000 / トリニティ・コマンド・S級侵略者)
- 🔹進化: 自分の水・闇・自然のいずれかのクリーチャー1体の上に置く。
- 🔹SSS級侵略[天災]: 自分の水・闇・自然のコマンドが攻撃する時、このカードを**バトルゾーン・手札・墓地・マナゾーンのいずれか**から、その攻撃しているクリーチャーの上に重ねてもよい。(宣言が必要。バトルゾーンからの移動は「出た」扱いにならない。)
- 🔹W・ブレイカー
- ▶別のクリーチャーの上に重ねた時、相手のクリーチャー1体を選び、破壊する/マナゾーンに置く/手札に戻す、のいずれかを行う。

## 4. エンジン実装のための整理

### 4.1 必要な仕組み(使うカード)

### 4.2 実装の進め方(提案)

1. **第1段階(まず動かす)**: キーワード能力(ブロッカー・ブレイカー・SA・S・トリガー)と、ブースト/ドロー/墓地肥やしだけで済むカード(A1, A2, A4, B1, B3, B8の前半、B11 など)。
2. **第2段階**: 選択呪文(A8, A9, B6, B9)、バウンス・破壊・ハンデス、free cast(B7, B5, B10)、ヨビニオン。
3. **第3段階**: 置換効果・EXライフ・侵略・進化(A6, A11, A15, B10, B12, B13)、カイザー・革命。
4. **第4段階**: オルゲイト(コピー)、ジ・ウォッチ(ターンスキップ)。

マルルデッキは第2〜3段階、5cザーディは第2〜3段階が中心で、**両デッキとも第3段階までで大半のカードが動く**見込み。

### 4.3 手元の公式裁定メモとの関係

`裁定メモ_水闇自然マルル_5cザーディ.md`(動画字幕の要約)に、以下の注意点が書かれている。実装時のテストケースにする価値が高い(ただし**公式Q&Aとの照合は未実施**と、そのメモ自身が書いている)。
- ヨビニオンの空振り(山札を全部めくっても出せない場合はシャッフル)
- キーナリーが止めるのは、そのクリーチャー自身の「出た時」のみ(他のクリーチャーが持つ誘発は止まらない)
- デッドダムド侵略の宣言が必要か、付与された能力(ジャストダイバー等)の引き継ぎ
- 呪文の選択肢は先に宣言し、上から順に処理する
- 置換効果は連鎖しない(ジャオウガの身代わりに破壊置換は使えない)

1. ~~**ザーディクリカ**のターン終了時能力~~ → **確認済み**(公式カード詳細ページ、2026-10-15): 「自分のターンの終わりに、そのターン自分が呪文を唱えていれば、相手のパワー5500以下のクリーチャーを1体破壊し、その後、カードを1枚引いてもよい」。破壊は強制、ドローは任意。実装(条件つきの誘発・破壊は強制・ドローは `may`)と一致。
2. **ジ・ウォッチ**の「ターンの残りをとばす」: 誰のターンでも使えるか、条件はこれだけか。
3. **ドギラゴン**: 革命チェンジに関する記述の有無(Wikiの要約が曖昧)。革命2・革命0の文言。
4. **5色の決断**: 「エレメント」の範囲(この2デッキの範囲ではクリーチャーとして扱えば足りると思うが、未確認)。
5. **ワクムテラス**: クリーチャー面の種族・パワーは要約ツールの出力が不確か(エンジンでは使わない項目)。
6. **カイザー**の割り込み召喚条件: 「マナをタップせずに」の細かい範囲(コスト軽減・踏み倒しの扱い)。
8. **ジャオウガ**の身代わり(公式カード詳細ページ、2026-10-15 に原文を確認): 「鬼S-MAX進化:自分がゲームに負ける時、またはこのクリーチャーが離れる時、かわりに自分の表向きのカードを3枚破壊してもよい」。"してもよい"で任意、対象は「自分の表向きのカード」3枚。**どのカードを破壊するかを誰がどう決めるか(選ぶのか)は、ページに明記がない**。実装は、価値の低いカードから自動で選ぶ(README の制限)。公式Q&A(鬼S-MAX進化の身代わり。Q&A 41461 / 44315 / 47923)で確認し、プレイヤーが選ぶなら質問()にする。
7. 各カードの**収録弾による文言の差**(同じカードでもエラッタ・表記の変更がある)。ここで使ったのは公式サイトで見られる最新に近い版。
