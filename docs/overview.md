# デュエマ シミュレータ(ブラウザ版)まとめ

## 目的

デュエマのシミュレータを作り、ロジック的なAIを組み込む。友達とのスターターデッキ対戦の再現や、デッキ分析にも使う。

複数機能を予定している。主に2つで、**CPU対戦**と**確率シミュレータ**。

確率シミュレータは、ある状態になるまで何ターンかかるか、最初のターンに◯◯がある確率などをシミュレートするもの。

## 技術スタック

| 項目 | 採用 | 理由 |
|---|---|---|
| 言語 | TypeScript | 型でルールの矛盾を検出でき、Claudeが書いたコードの事故が減る |
| ビルド | Vite | 軽量で、保存するとすぐ画面に反映される |
| UI | React + CSS | カード盤面はDOMとCSSで十分(Canvasやゲームエンジンは不要) |
| テスト | Vitest | ルール処理を単体テストし、Claudeが自己検証できる |
| 公開 | GitHub Pages / Cloudflare Pages | 無料。友達にURLを送るだけで遊べる |

## 設計方針

- ゲームロジックはUIから完全分離した純粋なTypeScriptにする
- 「状態 + 行動 → 新しい状態」のreducer方式で、状態を丸ごとコピーできる形にする
- 同じコードを、Node.jsでの数千試合の自動対戦とブラウザの対戦画面の両方に使う
- 重いAI探索はWeb Workerで動かし、画面が固まらないようにする

## 開発の段階

1. **コアルール**:山札、手札、マナ、シールド、バトルゾーン、ターン進行、勝利判定
2. **カードデータ**:JSONで定義。能力は少数のパターン(パワー、ブロッカー、W・ブレイカーなど)から始める
3. **ランダムAI**:合法手からランダムに選び、1試合が最後まで回れば成功
4. **ルールベースAI**:「マナを余らせない」など単純なロジック
5. **探索型AI**:モンテカルロ法(ランダムプレイアウトを多数回して手を選ぶ)

## できること

- AI同士の数千試合で、デッキの勝率やカード単体の強さを測る
- スターターデッキ同士の対戦を事前に再現する
- 後から、PeerJS(WebRTC)でサーバーなしのオンライン対戦、localStorageでデッキ保存を足せる

## 注意点

- 最大の壁はカードごとの能力処理。使うデッキ1〜2個分だけに絞る
- カード画像は権利の問題があるので、テキストだけの表示にする(外部公開の予定はないので、付けてもいいと思っている)
- カードデータは手入力になる
- Node.jsが必要
