## 1. ゲームの開始と勝敗

- デッキは**ちょうど40枚**。テキストで許されたカードを除き、同名は**4枚まで**【R 100.2 / 100.2a】。
- 開始手順: 山札をシャッフル・確認 → **山札の上から5枚を裏向きでシールドに展開し、5枚引いて手札にする** → じゃんけんの勝者が先攻(**後攻を選べない**) → 先攻の最初のドローはなし【R 103.2〜103.5 / 500.6】。
  - DM_SIM は先攻・後攻を「ランダム」か「選択」にできる(アプリ独自の拡張。spec 3.2)。
  - マリガンの定めは条文に**ない**。
- 勝利条件【R 104.2】:
  - 攻撃先が変更されないまま、相手のシールドが0枚の時にクリーチャーで攻撃が成立 → 勝利(a)。
  - 相手の**山札が0枚になった** → 即座に勝利(b)。効果の処理の途中で**一瞬でも0枚になれば**0枚とみなす。
  - **勝利条件と敗北条件を同時に満たした場合は勝利する**(c)。
- 勝敗は即座に確定し、ゲームは終了する【R 104.1】。ダイレクトアタックでの敗北・山札0枚での敗北は**状況起因処理**【R 703.4a / 703.4b】。
- 引き分けの規定は総合ルールに**ない**(DM_SIM のターン上限100での引き分けは、シミュレーション用の独自処理)。
- 数【R 108】: 整数のみ。パワーは修正でマイナスになりうるが、**参照する時は0**として扱う(108.1b)。∞は「それより大きい数を選べない数」(108.1c)。増減の計算順は **足す → 引く → 掛ける → 割る**(108.2)。パワーを倍にする効果は、他の増減の**後**に適用する【R 206.4】。

## 2. 絶対法則(効果の優先順位)

【R 101】

1. **カードの効果はルールに勝つ**(101.1)。
2. **「できない」は「できる」に勝つ**(101.2)。ただしカードはルールに勝つので、「できる」効果は「できない」**ルール**には勝つ(スピードアタッカーは召喚酔いに勝つ)。
3. **できることは全て行う**(101.3)。「〜したら」の条件は、その行為を**試みたこと**で成立し、結果は問わない(101.3a)。
4. **S・トリガー(S・バック、G・ストライク、サバキ Z を含む)を優先し、常にターン・プレイヤー側から**処理する(101.4 / 101.4a / 101.4b)。
   - 同時に発生した効果は、S・トリガー系をターン・プレイヤー → 非ターン・プレイヤーの順に処理し、**その後**、残りの効果をターン・プレイヤーから**好きな順番**で解決する(101.4a)。
   - 処理中に発生した効果は一度**待機**し、処理中のものを先に終える(101.4a)。非ターン・プレイヤーの処理中にターン・プレイヤー側の効果が発生したら、処理中のものを終えてからターン・プレイヤーの効果を優先する(101.4c)。
   - **置換効果以外**は、効果の処理中に割り込めない(101.4d)。
   - S・トリガー系の解決中に**新たに**シールドがブレイクされて同種の効果が待機した場合は、**すでに待機していたものより先に**、新しいものを解決する(101.4g)。
   - 能力・呪文の効果で起きたバトルは、そのバトルが終わるまで効果の一部(101.4e)。バトルする時に誘発する能力は即座に働く(101.4f)。
5. **置換効果は1つのイベントに1回だけ**。すでに置換されたイベントは、それ以上置換できない(101.5)。句点で区切られた範囲の文は、置換された後はもう置換されない(101.5a)。複数ある場合は**ターン・プレイヤーの置換効果を優先**し、同じプレイヤーの複数からは、そのプレイヤーが選ぶ(101.5b / 609.8)。

## 3. 文明・マナ・コスト

- 文明は光・水・闇・火・自然の5つ。文明を持たないカードは無色。**文明を選ぶ時、無色は選べない**【R 106.1〜106.3】。
- マナは、マナゾーンのカードを**タップ**して生まれる。タップしたカードが持つ文明の**うちひとつ**の文明のマナになる(通常1点)【R 107.2】。
- **コストの支払い**【R 112.2】:
  1. まず、コストに含まれる**文明を1文明につき1枚**、別々のマナゾーンのカードをタップして満たす。
  2. さらに、マナシンボルの数値の合計がコストと同じになるまで、不足分をタップする。
  - 多色カード1枚で複数の文明を同時に満たすことは**できない**(どれか1つの文明として扱う)(112.2a)。
  - コスト軽減で、コストが必要な文明の数より小さくなった場合は、**文明の支払いを優先**し、超過した分のマナは支払い終了時になくなる(112.2b)。例: コスト3に軽減された5文明のカードは、5枚タップできる。
  - 文明とコストの支払いが適切に完了していれば、**余分にタップすることはできない**(112.2c)。
- **コストを支払わずに実行**できる能力(S・トリガー、S・バック、ニンジャ・ストライク、サバキZ、G・ゼロ、アタック・チャンスなど)でも、「召喚する」「唱える」行為自体は行われるので、それによって誘発する能力は誘発する【R 112.3g】。S・トリガーの呪文は、**効果の解決までが**S・トリガーの能力、クリーチャーは**召喚までが**S・トリガーの能力(出たことで誘発する効果は別のイベント)【R 112.3a】。
- カードのコストを**参照する**時は、軽減前の**本来のコスト**を使う(コスト軽減の影響を受けない)【R 201.2a】。ツインパクトのコストを参照する時は、**効果を使ったプレイヤー**が好きな方を選ぶ【R 201.2b】。
- 実行の手順【R 601.1】: ①実行の宣言(コストの条件の変更も含む)→ ②カードは**保留状態**になる → ③文明を先に支払う → ④コストを増減する効果を適用して決定 → ⑤支払う → ⑥カードが実行される → ⑦選ぶものを指定する。同時に複数のものを選ぶ指示では**同じものを複数回は選べない**。「〜ごとに」選ぶ指示や、同じ能力が複数回効果を発揮する場合は、同じものを複数回選べる(601.1h)。
  - マナゾーンにあるカードを実行する時、**保留状態のそのカード自身をタップして**、コストと文明を支払える(601.1c)。

## 4. ゾーン

【R 400〜410】

- ゾーンは9つ(山札・手札・バトルゾーン・墓地・マナゾーン・シールドゾーン・超次元・超GR・深淵)。**バトルゾーンだけが共有**で、他は各プレイヤーごと(400.1)。
- 公開ゾーン: バトルゾーン・マナゾーン・墓地・超次元・深淵。非公開ゾーン: **シールド・山札・手札**・超GR(400.2)。
- 非公開ゾーンから条件に合うカードを探す時、**条件を満たすカードが存在しても、全てを見つける必要はない**(400.2g / 701.10b)。参照先がなければ、ゾーンを見せる必要はない(400.2d)。
- **ゾーンを移動したカードは、新しいカードとして扱われる**(以前の状態を引き継がない)(400.5)。**マナゾーンでタップしていたカードがバトルゾーンに出る場合は、アンタップ状態で出る**(400.5b)。
- バトルゾーン以外のゾーンの複数枚の移動は**同時**(400.7)。
- **山札**: 順序を変えてはいけない(401.2)。同時に複数枚を山札の上下に置く場合は、**持ち主が順序を決める**(401.4)。「上からN番目」に置く時、N枚なければ**一番下**(401.6)。
- **手札**: 上限なし(402.2)。
- **マナゾーン**: カードは逆さま(縦向きの上下逆)で置く。**多色カードはタップして置く**(405.1)。表向きが通常。裏向きのカードは、コスト0・無色・マナ数1の他に特性を持たないカードとして扱う(405.4)。
- **シールドゾーン**: 1枚ずつ裏向きの束。並べ替えられない(406.2 / 406.3)。
- **保留状態**【R 409】: カードを実行した時、または効果でバトルゾーンに出る時、実際にゾーンを移動するまでの間、そのカードは**保留状態**になる。
  - 保留状態でも元のゾーンを離れたことにはならない(409.1)が、**そのゾーンの枚数には数えない**(409.1c)。例: 手札の最後の1枚の呪文を唱えている最中、手札は0枚。唱えている呪文自身を捨てることはできない。
  - 呪文は、唱えてから効果の解決が終わるまで保留状態(409.1b)。解決後に墓地へ置く。
  - 複数のカードを同時に実行・出す場合は、全てが保留状態になってから**1枚ずつ**処理する(409.1e / 409.1f)。
  - 保留状態が解けて元のゾーンに戻った場合は、そのゾーンに**置かれたことにはならない**(誘発しない・位相も変わらない)(409.2a)。ただし、**呪文が墓地に置かれる時の置換効果(チャージャー等)は、墓地から唱えた場合も適用される**(409.2b)。
  - 保留状態になる前に与えられていた効果は、保留状態でなくなった後は失われる(409.1d)。
  - **次のターンに移行する時**、保留状態のカードは全て墓地に置かれる。新しい能力はトリガーしない【R 512.1】。

## 5. ターンの進行

【R 500〜512】

| ステップ | 内容 |
|---|---|
| ターン開始 | ターン・プレイヤーが、バトルゾーンとマナゾーンの自分のカードを**同時にアンタップ**(ターン起因処理。効果で妨げられることがある)。その後「ターンのはじめに」誘発する能力が誘発(501) |
| ドロー | 1枚引く(ターン起因処理)。**先攻の第1ターンは飛ばす**(500.6 / 502) |
| マナチャージ | 手札から1枚をマナゾーンへ(任意。通常1枚まで。継続的効果で増減)(503) |
| メイン | カードを実行できる(通常、メインステップのみ)(504) |
| 攻撃 | 攻撃クリーチャー指定 → ブロッククリーチャー指定 → バトル → ダイレクトアタック → 攻撃終了(505) |
| ターン終了 | 「ターンの終わりに」の誘発。「そのターン中」「ターンの終わりまで」の効果が同時に消滅(511) |

- 一度次のステップに移ったら、前のステップには戻らない(500.2a)。
- 効果の期限【R 500.3】: ステップ・サブステップの「終わりまで」の効果は終わりで消滅。「〜まで」は**そのステップの開始時に**消滅。「攻撃中」は各クリーチャーの**攻撃終了時**に消滅(攻撃ステップの終了時ではない)。「ターン中」は**ターンが完全に終了した後**に消滅する。
- 追加ターンは、現在のターンの**直後**に1つずつ追加する。同じターン中に各プレイヤーが追加ターンを得た場合は、ターン・プレイヤーから(500.5 / 500.5a)。
- 「ターンのはじめに」誘発する能力を持つカードが、**そのターン開始ステップ中に**誘発可能なゾーンへ移動した場合、その能力は**次のターン開始ステップまで**誘発しない(501.2a)。

### 5.1 攻撃ステップ

- ターン・プレイヤーのクリーチャーは、**非ターン・プレイヤーと、そのプレイヤーの「タップ状態」のクリーチャー**を攻撃できる(505.2)。1体ずつ攻撃・ブロックする(505.4)。攻撃可能なクリーチャーがいる限り、何度でも攻撃できる(505.5)。
- 攻撃クリーチャーの条件【R 506.1a】: **アンタップ状態**で、**そのターンの開始時から継続してバトルゾーンにいる**か、効果で攻撃できないことが無効になっていること。攻撃するための条件を満たせないクリーチャーは指定できない。
  - 攻撃を強制する効果がある場合、そのターン中に必ず攻撃させる。順番は任意(506.1b)。
  - 指定したらタップする(506.1c)。プレイヤーを攻撃するかタップ状態のクリーチャーを攻撃するかを指定する(506.1e)。
  - 攻撃クリーチャーが指定されなかった場合、他のサブステップは飛ばされる(506.2)。
- 「攻撃する／される」で誘発する能力は、**攻撃クリーチャーに指定された時点**でのみ誘発する。指定後に特性が変わって条件に合っても誘発しない(506.3a)。
- 誘発の処理順【R 506.3 / 507.3 / 511.1】: 使用宣言が必要な誘発型能力(ニンジャ・ストライク、革命チェンジなど。非公開ゾーンで誘発する能力)は、まず**ターン・プレイヤー側が全て宣言** → ターン・プレイヤーの待機状態の効果を好きな順で処理 → **非ターン・プレイヤーが宣言**(攻撃指定時点で条件を満たしていなかったものも、この時点で満たしていれば可)→ 非ターン・プレイヤーの効果を処理(途中でターン・プレイヤー側の効果が誘発したら、処理中のものを終えてからそちらを先に)。
- **ブロック**【R 507】:
  - 非ターン・プレイヤーは、攻撃先を変更する能力(ブロッカー、ガードマンなど)を使うクリーチャーを選ぶ(507.1)。複数体を同時に選ぶことができ、**最後に解決した能力で攻撃先が変更され**、それが「ブロッククリーチャー」になる(507.1a / 507.2 / 507.2a)。
  - 選べないもの: ブロッカーを持つ**タップ状態**のクリーチャー、プレイヤー攻撃中の**ガードマン**、「ブロックされない」攻撃への**ブロッカー**、**攻撃されているクリーチャー自身**(507.1a の例)。
  - ブロックを強制する効果がある場合は、必ず選ぶ(507.1b)。
  - ブロックされたクリーチャーは、ブロッククリーチャーが「その攻撃」から取り除かれても**ブロックされたまま**(507.2c)。
- **「その攻撃」から取り除かれた**クリーチャー(場を離れる・効果で除かれる)は、攻撃クリーチャーでもブロッククリーチャーでもなくなる(505.6)。攻撃クリーチャーまたは攻撃先のクリーチャーが除かれたら、**その攻撃は即座に終了**し、攻撃終了ステップに移る。解決待ちの効果は解決されるが、非ターン・プレイヤーの任意の使用宣言を新たに追加することはできない(505.6a)。攻撃中にタップ・アンタップしても、攻撃からは取り除かれない(505.6b)。
- **バトルステップ**: 攻撃クリーチャーが**クリーチャーを攻撃している**か、攻撃先が変更されていればバトルが発生する(508.1)。

### 5.2 バトルとシールドブレイク

- **バトル**【R 115 / 701.13】:
  1. バトルを開始すると、まず「バトルする時」などで**誘発する能力が誘発**し、ターン・プレイヤーから処理する(115.2)。**パワーを比べる前に解決する**(701.13a)。
  2. この時点でどちらかが破壊・取り除かれていれば、**バトルは行われない**(115.3a)。
  3. パワーを比べ、**高い方が勝ち、低い方は負ける**。**同じなら両方負ける**。負けたクリーチャーは破壊されて墓地へ(状況起因処理)(115.3b / 701.13a / 703.4d)。
  4. 「バトルに勝つ」能力を持つクリーチャーは、パワーに関係なく勝つ。双方が持つ場合は両方勝ち、負けたクリーチャーは存在しない(115.3c / 700.5)。
  5. バトルの結果(勝った時・負けた時・破壊された時)で誘発した能力を解決し、そこで新たに誘発した効果も**その時に**解決する。全て終わったらバトルが終了(「バトル中」の効果が消滅)(701.13b / 701.13c)。
  6. その後、スレイヤーなどの「**バトルの後**」の能力が誘発・解決する(701.13d)。
  7. 攻撃以外の**効果で起きたバトル**の処理中は、そのバトルが始まる前に待機していた効果は解決されない(701.13e)。
- **ダイレクトアタック**【R 509.1】: 攻撃先が変更されておらず、この時点で非ターン・プレイヤーに**シールドがなければ**ダイレクトアタック。受けたプレイヤーは敗北(状況起因処理)。
- **シールドブレイク**【R 509.2〜509.6】:
  - 非ターン・プレイヤーにシールドがある場合、ブレイクする数を決める。何も書かれていなければ**1つ**。W・ブレイカーなどは指定の数(509.2a / 509.2b)。
  - **複数のブレイカー能力を持つ場合、どの能力を使うかを選ぶ**。T・ブレイカーとW・ブレイカーを持つクリーチャーで、W・ブレイカーを指定して2つブレイクすることはできるが、**どちらも指定せずに1つだけブレイクすることはできない**(509.2c)。
  - ブレイクするシールドを、指定の数だけ**選ぶ**(509.3)。「ブレイクする前に」の能力は、この時点で誘発し、**シールドをブレイクする前に**解決する(509.3 / 509.4 / 603.7)。その効果の解決でクリーチャーが場を離れても、**すでに選んだシールドはブレイクされる**(509.4c)。
  - 選んだ数を**同時に**ブレイクする。ブレイクしたシールドが指定の数に達しなくても、**新たに加えたシールドを追加でブレイクするシールドとして選ぶことはできない**(509.5)。同じシールドを2回選ぶことはできない(509.6)。
  - **効果で複数枚のシールドがブレイクされる時**は、同時に手札に移動する(701.14c。ブレイカー能力によるブレイクとは異なる)。シールドを「手札に加える(戻す)」効果は、ブレイクと**同じ挙動**だが、「ブレイクした」ことを条件とする効果は適用されない(701.14b)。
- **S・トリガー等の宣言**【R 113.6 / 509.5a〜509.5e / 112.3a】:
  1. ブレイクされたシールドが手札に加わる時、持ち主は S・トリガー・G・ストライク・S・バックの**使用宣言**ができる。宣言するカードは**相手に見せる**。複数枚は**同時に**宣言する。
  2. 宣言が全て終わってから、シールドは手札に移動する。待機状態のシールドは、シールドゾーンにあるが**シールドの数には数えない**(113.6a)。
  3. 手札に加えたカードに「裁きの紋章」があれば、それを捨てて**サバキZ**を宣言できる(509.5d)。
  4. その後、S・トリガー・S・バック・G・ストライク・サバキZを**好きな順序で**解決する(509.5e)。
  - S・バックは、シールドから手札に加わるカードを**墓地に捨てて**宣言する。この時捨てたカードは「**手札から捨てたカード**」として扱う(509.5c)。
  - シールドゾーンのカードが持つ「S・トリガーを与える」能力は、**手札に加わるシールドが待機状態になる直前**の状況を参照する(113.6b)。

## 6. 能力・効果の処理

【R 110 / 600〜609 / 700 / 703】

- 能力は4種: 呪文能力・**誘発型**(「〜時」「〜場合」「〜たび」)・起動型・**常在型**(110.3)。
- **どのゾーンで機能するか**(110.4): 呪文能力は呪文の処理中。ゾーンの指定がない能力は**バトルゾーンでのみ**機能する(110.4c。ただし「S・トリガーを得る」能力はシールドゾーンでも機能)。ゾーンが書かれている能力はそのゾーンでのみ(110.4b)。カード自身の実行に対する限定・修整(シンパシーなど)は、**実行しようとするゾーン**(通常は手札)で機能する(110.4e)。
- **効果の発生源**: いったん誘発した効果は、発生源とは**独立した待機状態**になる。発生源が別のゾーンに移動しても効果は消えない(110.5a)。
- **誘発**【R 603】:
  - 誘発条件を満たすたび、自動的に誘発する(603.2)。1つの出来事が複数を含む場合は、その数だけ誘発する(603.2b。例: 複数のクリーチャーが同時に破壊されれば、「破壊されるたび」はその数だけ)。
  - 「**〜になる**」を使った誘発イベントは、その状態に**変化した時のみ**誘発する。元々その状態だった場合や、その状態でゾーンに入った場合は誘発しない(603.2c)。
  - **置換されて行われなかったイベント**では誘発しない(603.2d)。置換後のイベントによる誘発はする(609.4)。
  - 能力は、誘発した瞬間に**待機状態**になる。実行中・解決中でもいつでも誘発する(111.2a)。
  - **誘発型能力に条件がある場合、解決の時点で満たしていれば解決される。誘発した時点で満たしているかは問わない**(603.4 / 605.2a)。
  - **ゾーン変更誘発**(603.5): 「バトルゾーンを離れた時」に誘発する能力は、そのイベントの**直前**の存在・状態に基づく(603.5c)。その能力を持つカード**自身**が離れた時にも誘発するが、**過去の状態を見ることができるのは、その能力を持つカード自身についてのみ**(603.5d)。例: 「クリーチャーが破壊された時、カードを引く」を持つクリーチャーと他の2体を全破壊すると、誘発は**そのクリーチャー自身の1回のみ**。
  - 特性を追加・変更する継続的効果は、ゾーンに置かれた**瞬間に**適用される。特性を条件に持つ誘発は、適用後の特性で判定する(603.5b / 608.3c)。
  - **遅延誘発型能力**は、生成された後のイベントにのみ働く(さかのぼらない)(603.6a)。
- **解決**【R 605】:
  - 待機状態の効果は、**ターン・プレイヤーから、自分の効果を好きな順番で**解決する。**効果がいつ待機したかの順番は関係ない**(605.1)。
  - 選ぶ指示は、指定できる範囲で可能な限り選ぶ。選べなければその効果は何もしない。「すべて」と書かれていれば、選んでいるわけではない(605.2b)。
  - **書かれた順序で**解決する(置換効果で後の指示の意味が変わることはある)(605.2c)。
  - ゲームの情報が必要な時、その値は**処理を行う時に一度だけ**決まる(605.2d)。エレメントがすでに場を離れている時は、**離れる直前の情報**を参照する(605.2e)。
  - 呪文は、解決の最終段階で墓地に置かれる(605.2f)。
  - 山札からカードを実行する・出す効果で、山札を見ている・表向きにしている間、その中の**実行する以外のカード**は山札に属するが、他の効果の影響を受けない(605.4)。
- **効果**【R 606〜608】: 実現不可能なら**可能な部分だけ**行う(606.2。例: 手札が1枚なら「2枚捨てる」はその1枚だけ)。継続的効果は、期間が明記されていなければゲーム終了時まで継続(608.2a)。変数を含む場合、値は**解決時にのみ**決まり、その後変化しない(608.2b)。常在型能力が生む継続的効果は「固定」されず、対象全てに常に適用される(608.3a)。
- **置換効果**【R 609】: 「かわりに」を使う効果は置換効果(609.1a)。**イベントが発生する前**に存在していなければならない(609.2)。1イベントにつき1回だけ適用(609.3)。置換されたイベントは起こらなかったことになり、**変更後のイベントが発生**する(609.4)。変更後のイベントが行えない場合は、置換できない(609.4)。**呪文自身の効果が自身の移動を置換する場合は、他の置換効果より優先**する(609.8a。チャージャー等)。複数のイベントが同時に起きる場合は、ターン・プレイヤーから、どのイベントにどの置換効果を適用するかを決め、同時に適用する(609.9)。
- **選択肢**【R 700.2】: 選択肢を持つ能力は、**能力を解決する際に**選択肢を選ぶ。相手に選ばせる場合も、そのプレイヤーが解決時に選ぶ(700.2a / 700.2b)。
- **破壊されない／離れない**クリーチャーは、パワーが0以下になっても破壊されず離れない(700.3)。
- **状況起因処理**【R 703】: ゲームが条件を**常に確認**し、該当するもの**全て**を同時に単一のイベントとして処理し、処理後に再びチェックする(703.3)。他の効果を処理するより**前**に行い、能力の解決中でも優先する(703.1 / 111.2d)。主なもの: ダイレクトアタックで敗北・山札0枚で敗北・**パワー0以下のクリーチャーを破壊**・バトルに負けたクリーチャーを破壊・進化エレメントの再構築・適正なタイプを持たない表向きのカードを墓地へ(703.4a〜703.4m)。
- **ターン起因処理**【R 702】: ステップ開始時の最初に行う(状況起因処理のチェックや、誘発型能力の待機より**前**)。アンタップ、ドロー、攻撃クリーチャーの指定、ブロッククリーチャーの指定。

## 7. 用語(キーワード処理)

【R 701】要点のみ。

| 用語 | 定義 |
|---|---|
| 破壊する | バトルゾーンから墓地に置こうとすること(701.6) |
| 捨てる | 手札から墓地に置くこと。通常は**影響を受けるプレイヤーが選ぶ**。ランダム・他のプレイヤーが選ぶ効果もある(701.7) |
| チャージする | 手札からマナゾーンへ上下逆に置くこと(701.8) |
| 探す | そのゾーンの全てを見て条件に合うカードを見つけること。**全てを見つける必要はない**。見つけたカードを見せる指示がなければ見せなくてよい(701.10) |
| シャッフルする | 順番が誰にも分からなくなるよう無作為化すること(701.11)。探したカードを山札の特定の場所に置く効果では、それらを除いた山札だけをシャッフルする(701.11b) |
| 選ぶ | 効果で決められた数のカード・エレメントを指定すること。テキストに「選ぶ」がなければ、決められた数に影響する効果でも**選んだことにはならない**(701.34。《ヴェネラック-F5》の例) |
| 入れ替える | 2つのゾーンのカードの場所を交換すること。バトルゾーンのエレメントを入れ替える効果で、置換などにより移動が正常に行われない場合、**入れ替え自体が行われない**(701.26) |
| 実行する | コストを支払ってカードが効果を成せる状態にすること。召喚する・唱える・ジェネレートする・タマシードの実行などの総称(701.5) |
| 召喚する / 唱える | コストを支払って、クリーチャーをバトルゾーンへ出せる状態にする / 呪文を実行する。通常はメインステップのみ(701.3 / 701.4) |
| シールド化する | カードを裏向きの新しいシールドとしてシールドゾーンに置くこと。表向きにシールド化することもある(701.32) |

## 8. 特別なカード(DM_SIM に関係するもの)

- **進化クリーチャー**【R 801】:
  - 適正な進化元がなければ**出せない**(801.1a)。進化元は好きな順で下に重ねる(801.1b)。
  - **進化しても、進化前のカードと同一のクリーチャーとして扱う**。タップしていればタップのまま。進化元に適用されていた効果は、進化後も適用され続ける(801.2)。攻撃中に進化しても攻撃は続行(801.2a)。2枚以上から進化し、タップ・アンタップが混在する場合は**タップして**出る(801.2b)。
  - **進化クリーチャーは召喚酔いしない**(801.3)。
  - **再構築**(801.4 / 703.4h): 進化エレメントとして表出しているカードがバトルゾーンを離れる時、その下のカードが適正な状態で残る。直下が単独で存在できるカードならそのまま残し、できなければ墓地に置く(801.4a)。複数枚ある場合は、一番上の単独で存在できるカードを残し、他はその下に重ねたまま(801.4b)。再構築で残ったカードは**新たに出たことにはならない**(出た時は誘発しない)。進化元のターン開始時からいたなら新たに召喚酔いしない(801.4c)。
  - **進化クリーチャーが場を離れる時の「下のカード」の扱い**: 進化クリーチャーであれば、一番上のカードは「クリーチャーとして」離れ、**下のカードは「単なるカードとして」離れる**(109.2b)。つまり、クリーチャー(エレメント)を破壊・手札に戻す・マナゾーンに置くなどの効果では、**山全体が一緒に動く**(旧 Q&A 37345: 墓地に置かれる時も手札に戻される時も、下のカードも一緒に動く)。
  - **再構築が起きるのは、一番上のカードだけが離れる場合**(カード単体を指定した除去、侵略で別のクリーチャーの上に移る、**スター進化**の置換効果(813.1)など)【二次: DMwiki「再構築」。出典の公式 Q&A として 40118〜40121 / 40524 / 41073 / 41074 / 41080 / 41646 が挙げられている。未確認】。
  - DM_SIM は、`moveCards` が山全体を動かし、侵略は `enterBattle` が元の山から1枚だけ抜く(下のカードが残る)ので、この区別は**結果として合っている**。カード単体の除去とスター進化は、対象カードにないため未実装。
- **カードを選ぶ効果**: 選ばれるのは**そのカード自身のみ**。進化クリーチャーなどでも、指定されたカードだけが直接影響を受ける(109.2a)。**エレメント**を選ぶ効果は、構成する全てのカードが影響を受ける(316.3)。
- **S-MAX進化クリーチャー**【R 815】: 進化元を必要とせずに出せる進化クリーチャー。**1人につき1体**しか存在できず、2体以上ある場合は1体を残して残りを**手札に戻す**(常在型能力)。
- **ツインパクト**【R 810】: 2つのコスト・カードタイプを持つ。**カードとして参照される時は、適正なカードタイプのうち、持ち主が好きな方を選べる**(810.3)。カード名は2つが合わさった名前。**バトルゾーンにクリーチャーとして存在する時は、クリーチャー側のみ**を参照する(810.4)。
- **ドリーム・エレメント**(ドギラゴンなどのドリームレア)【R 817】: バトルゾーンにある間、持ち主は**同名のエレメントを出せない**。何らかの方法で同名が2つ以上存在することになった場合は、**両方残る**。
- **特性の無視**: 進化元などカードの下に置かれたカードは、通常の特性が無視される(200.3a)。ただしカードを指定する時は特性を参照する(例外: 超魂Xなど)。

## 9. キーワード能力・個別カードの裁定(公式 Q&A)

**総合ルールには、これらの個別定義がない**([rules-sources.md](./rules-sources.md) 2章)。カードの注釈文、公式 Q&A、変更点が根拠になる。以下は要約。**原文は URL 先で確認する**。

### 9.1 ジャストダイバー

- カードテキスト上は「ジャストダイバー」の語だけ(注釈文なし)で、公式カード詳細ページ(例: 《魔誕の斬将オルゲイト》)も同様。
- **誘発型能力として扱われ、その解決によって継続的効果が生まれる**。出たクリーチャーが対戦相手全員に選ばれず、攻撃されなくなる期間は、**次の自分のターンのはじめまで**【変更点 2023-10-18 / 総合ルール 300.3】。
  - <https://dm.takaratomy.co.jp/rule/rulechange/316651/>
- 公式 Q&A は一貫して「**『出た時』にトリガーする能力**」と回答している:
  - 【Q&A 40523】相手の《地封龍 ギャイア》がいる時、ジャストダイバーを持つクリーチャーは出るかわりにマナゾーンに置かれる(置換効果が適用される)。
  - 【Q&A 40533】《界王類絶対目 ワルド・ブラッキオ》がいる時、ジャストダイバーは**トリガーしない**。「出た時」にトリガーする能力なので置換効果の対象になる。
  - 【Q&A 40524】再構築で残ったクリーチャーは新たに出ていないので、「出た時」もジャストダイバーも**トリガーしない**。選ばれるし、攻撃もされる。
  - 【Q&A 43289】別のクリーチャーの上へ移動(侵略など)しても効果は残る。進化クリーチャーに与えられていた効果は、重なった先のクリーチャーと、再構築で残った進化元の**両方に引き継がれる**。
  - 【Q&A 40847】トリガーした能力は**ターン・プレイヤーから解決**する。相手のジャストダイバーの解決より前に、自分の「破壊された時」の能力で、出た相手のクリーチャーを破壊できる。
- 継続的効果が生まれるのは**解決の時点**なので、解決される**まで**は選べる・攻撃できると読める(DMwiki の解説も同じ)。⚠ 解決前の扱いを明記した公式 Q&A は取得できていない。

### 9.2 ヨビニオン

- 【Q&A 45263】山札を表向きにしていき、**最初に表向きになったのが、出せない進化クリーチャー**(進化元がない)だった場合は、**表向きにしたカードをすべてシャッフルして山札の下に置き**、処理を終了する。
- 【二次】クリーチャーのヨビニオンは**召喚によって出た時**に働く。出したクリーチャーは召喚ではないので、そのクリーチャーのヨビニオンは連鎖しない。表向きにしたカードだけをシャッフルして山札の下へ戻す。
- ⚠ 山札に踏み倒し先がない場合は「山札を公開するだけ」とされるが、Q&A の原文は未確認。

### 9.3 EXライフ

- **2つの要素**を持つ: 出る時に山札の上1枚を EXライフシールドにする(状態定義効果)と、離れる時にかわりにそのシールドを墓地に置く(置換効果)【二次】。
- 【Q&A 40839】進化しても、進化元の EXライフシールドが残っていれば、そのシールドが EXライフシールドであるという**情報は引き継がれる**。
- 【Q&A 42663】EXライフを持つクリーチャーの上に、EXライフを持つ進化クリーチャーが進化した場合、進化元の EXライフは進化後の EXライフとしても扱われ、**離れる時にかわりに墓地に置ける**。
- 【Q&A 39551】クリーチャーの能力が**無視されている**間は、EXライフの置換効果は適用できない(出る時のシールド化は、バトルゾーンにいるクリーチャーの能力を無視する効果の影響を受けない)。無視が終われば、追加されたシールドは EXライフシールドとして扱われる。
- 【Q&A 39547】一度シールドゾーンを離れた EXライフシールドの紐づきは解除される。同じ位置に新しく置いたシールドは EXライフにならない。
- ⚠ 進化クリーチャー自身がEXライフを持たない場合に、進化元の EXライフシールドを身代わりにできるかは、取得できた Q&A では確定しない。

### 9.4 ハイパーエナジー

- 【カード注釈(《魔誕の斬将オルゲイト》)】召喚する時、**コストが異なる**自分のクリーチャーを好きな数タップしてもよい。タップした**1体につき**、召喚コストを**2**少なくする。ただし、コストは**0以下にはならない**。
- 【Q&A 45936】ハイパーエナジーを複数得た場合(《陽炎の精霊メルキウス》2体)、それぞれのハイパーエナジーを個別に使える(2体を1体ずつタップして合計4軽減)。

### 9.5 シンパシー

- 【Q&A 49428】「W・シンパシー」などで与えられた能力でも、手札のクリーチャーの**最低コストは、そのクリーチャーの文明数**で決まる(1文明・無色は1、2文明は2、3文明は3…)。これは R 112.2b と整合する。
- 【Q&A 40363】シンパシーの数える対象が1つも存在しなければ、シンパシーは適用されず、**下限の「0以下にはならない」も適用されない**(無色クリーチャーを数えるカードで、無色がいなければコスト0で支払える)。

### 9.6 マッハファイター / スピードアタッカー

- 【Q&A 31690 / 31691】**マッハファイター**は、出たターンのみ、**タップ・アンタップを問わず相手のクリーチャーを攻撃できる**。**プレイヤーは攻撃できない**。出た次のターン以降は、アンタップ状態のクリーチャーは攻撃できない。
- 【Q&A 46491】マッハファイターは、それを持つカードの**常在型能力**。その上に重ねた進化クリーチャーには引き継がれない(下のカードの能力は無視される。R 200.3a)。
- 【Q&A 47376】《轟く邪道 レッドゾーン》の効果下では、マッハファイターで、アンタップ状態の「ジャストダイバー」を持つクリーチャーも攻撃できる。⚠ 要約のみ。
- スピードアタッカーは、出たターンから攻撃できる(プレイヤー・**タップ状態**のクリーチャーが対象。アンタップ状態のクリーチャーは攻撃できない)。召喚酔いルールに勝つ(R 101.2)。【spec 3.6。違いを説明した公式 Q&A は 31690。⚠ 原文未確認】

### 9.7 侵略

- 【Q&A 42940】**使用宣言した侵略は、解決時に取りやめられない**(「重ねてもよい」と書かれていても)。使用宣言が必要な誘発型能力は、宣言した時点で必ず使う。
- 【Q&A 40262】宣言後、解決時に攻撃中のクリーチャーが侵略の条件を満たさなくなっていても、**進化条件を満たしていれば**進化できる。
- 【Q&A 40435】複数の侵略を使う場合は、**効果を解決する前に、全ての使用宣言を行う**。その後、攻撃クリーチャーの「攻撃する時」の能力と各侵略を好きな順に解決する。
- 【Q&A 40437】侵略の条件は、**クリーチャーが攻撃した時点**で判定される。攻撃後に別の侵略で条件が変わっても、あとから条件を満たす侵略は使えない。
- 【R 506.3b / 603.2e】侵略は手札(非公開ゾーン)で誘発するため、**使用宣言が必要**。

### 9.8 G・ストライク

- シールドゾーンから**手札に加わる時**に、相手に見せて**使用宣言**する。解決時に、相手のクリーチャー1体を選び、攻撃できなくする。S・トリガー、S・バックと同じタイミングで宣言する(R 113.6)。【Q&A 39516 / 40695】
- 能力の使用を宣言すれば、その後カードが手札に加わらなくても使える。シールドゾーンのカードの能力が無視されていても、G・ストライクは無視されない。【Q&A 40941 他。⚠ 要約のみ】
- 解決順は S・トリガー・S・バックと**好きな順**(R 509.5e)。

### 9.9 S-MAX進化(鬼S-MAX進化)

- S-MAX進化クリーチャーは1人1体まで。2体目が出ると、1体を残して手札に戻す(常在型)(R 815.1a)。
- 【Q&A 41458】鬼S-MAX進化の置換効果は、**置換効果に対しては適用できない**(《水上第九院 シャコガイル》の勝利効果は置換効果なので、負けを置換できない)。⚠ 要約のみ。
- 【Q&A 41461 / 44315 / 47923】鬼S-MAX進化の身代わりで破壊するカードの範囲、2体目を出した時の「手札に戻す」の扱い。⚠ 原文未確認。
- 【Q&A 49086】《禁鬼機関 ジャオウガ-8》の効果で墓地から《CRYMAX ジャオウガ》を実行する場合も、**召喚コストを支払う**。

### 9.10 ターンの残りをとばす

- 【Q&A 46393 / 旧Q&A 36834】《終末の時計 ザ・クロック》でターンの残りをとばした場合、**そのターンの終わりにトリガーする能力はトリガーせず、使えない**。ターンの終わりに山札の下に置かれるはずのクリーチャー(アビスラッシュ)は、**バトルゾーンにとどまる**。
- 【Q&A 43863】相手の《芸魔王将 カクメイジン》が「各ブレイクの前に」で呪文を唱え、自分の《ジ・ウォッチ》でターンの残りをとばした場合、**選ばれていたシールドはブレイクされない**(とばす効果の解決が、シールドのブレイクより前だから)。
- 【Q&A 45931】すでにトリガーして待機している《ジ・ウォッチ》の能力は、その後に相手が効果で「クリーチャーの能力を無視」しても、**無視されない**(R 603.2)。相手は、呪文の解決後にターンの残りをとばせる。
- 【二次】相手のターンにも使える。「このターン」「ターンの終わりまで」の継続的効果は終了する。

### 9.11 「N回選ぶ」呪文(決断)

- 【Q&A 45918】《魔誕と光喜と楽識と炎怒と哀樹の決断》で、全文明が揃っている場合でも、**全てを1回ずつ使う必要はなく**、同じ選択肢を2回選んでもよい(「全部使う」は任意)。
- 【Q&A 45917】全てを1回ずつ使う場合でも、**置換効果が適用されたことにはならない**(「2回選ぶ」を「全種類を1回ずつ選ぶ」に置き換えるだけで、各選択肢の効果は置換されたイベントではない)。
- 選んだものは、**能力の文章の上に書かれたものから順に**解決する(R 101.4g の例)。複数回選ぶ時は、**解決の前にまとめて選ぶ**。

### 9.12 その他

- 【Q&A 43747】《終末縫合王 ザ=キラー・キーナリー》がいても、「**リンクした時**」の能力は**トリガーする**(出たことによってトリガーする能力ではないため)。⚠ 「他のクリーチャーが持つ『出た時』」「『クリーチャーが出た時』に誘発する能力」の扱いは、関連質問(2025-08-08 など)の回答を未確認。
- 【Q&A 48934】《魔誕の斬将オルゲイト》で、相手のターン中に相手の「ファイナル革命」の能力を使う場合、自分が**そのターンに使ったファイナル革命の回数**で数える(2つ目は使えない)。「極限ファイナル革命」はゲーム中に1回。
- 【Q&A 49031】《流星のガイアッシュ・カイザー》の FAQ。「マナをタップせずに」の範囲(コスト軽減・コストを支払わない実行)を扱う回答は、取得できた範囲では**確認できなかった**。
