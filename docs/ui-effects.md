# 対戦画面の演出(ターン遷移・攻撃・シールドブレイク)

シミュレータとしての正確さに加え、カードゲームとして「いま何が起きたか」が見て分かるよう、見せ場に演出を足す。
**演出は見た目だけの層**で、ゲームの進行と CPU の手の選択には関与しない。設計の約束(§1)を最初に置く。

実装: [src/ui/fx.ts](../src/ui/fx.ts)(判定・長さ・設定。純粋関数)/ [src/ui/FxLayer.tsx](../src/ui/FxLayer.tsx)(オーバーレイ)/ [src/ui/styles.css](../src/ui/styles.css) 末尾の「演出」/ テスト [tests/ui/fx.test.tsx](../tests/ui/fx.test.tsx)。

## 1. 設計の約束

1. **演出は engine のイベント(`Ev`)から作る。** `cuesOf(state, events, me)` は純粋関数で、状態を読むだけ。engine・AI・Worker・棋譜(`GameRecord`)には触れない。
2. **CPU の手の決定は演出に依存しない。** `chooseWithWorker` への入力は「状態 + シード」だけで、シードは `cpuSeed(hashSeed(setup.seed), 経過した手数)`。時間・演出・画面の状態は入らない。演出が CPU に与える影響は、**次の手を打つまでの待ち時間だけ**(`cpuWaitMs`)。同じシードなら、演出の有無で行動列が一致する(テストで固定)。
3. **演出スキップ設定ですべて無効になる。** オフにすると、次の3つが全部止まる。
   - オーバーレイ(`FxLayer` は何も描かず、タイマーも持たない)
   - CSS アニメーション(盤面のルートの `.fx` クラスが付かない。動いたカードの強調は、静止した枠だけになる)
   - 演出のための CPU の待ち時間(`fxEnabled=false` では従来と同じ間隔)
4. **隠れた情報を出さない。** シールドブレイクは枚数だけ(カード名なし)。名前を出すのは、公開された場面(召喚・呪文・攻撃宣言・トリガー宣言)のカードだけ。
5. **操作を妨げない。** オーバーレイは `pointer-events: none`・`aria-hidden`。演出中も、人間は盤面を操作できる。

## 2. 演出の一覧

| 種類 | きっかけ(イベント) | 表示 | 長さ |
|---|---|---|---|
| `turn` | `stepStart`(step=start) | 「あなたのターン / 相手のターン」+ N ターン目(観戦は「プレイヤーNのターン」) | 1200ms |
| `summon` | `entered`(via=summon) | カード名 + 「召喚」 | 600ms |
| `invade` | `entered`(via=invade) | カード名 + 「侵略」 | 800ms |
| `cast` | `cast` | カード名 + 「呪文を唱えた」 | 800ms |
| `attack` | `attackDeclared` | 「攻撃!」+ 攻撃元 → 相手 | 700ms |
| `block` | `blocked` | 「ブロック!」 | 600ms |
| `shield` | `shieldBroken`(続けて割れた分は ×N にまとめる) | 「シールドブレイク!」+ 盤面のシールドが揺れる | 800ms |
| `trigger` | `triggerDeclared` | 「S・トリガー!」「G・ストライク!」 | 1000ms |

- **自分で行った召喚・呪文・攻撃宣言は出さない**(本人が分かっているので、テンポを落とさない)。観戦(CPU 同士)では全部出す。ターン遷移・ブロック・シールドブレイク・トリガーは、自分の分も出す。
- 1手の演出は最大 4 件・合計 2600ms(`FX_MAX_CUES` / `FX_MAX_TOTAL_MS`)。長い連鎖でも、CPU が際限なく遅くならない。ターン遷移は、合計を超えても残す。
- 複数あれば順番に出す(`FxLayer` の列)。
- 盤面の動き(`.game.fx` の時だけ): 動いたカードの「ぽんと出る」アニメーション、シールドの揺れ、勝敗パネルの拡大表示。

### 2.1 軽い演出(ドロー・ステップの切り替わり)

画面の左上に小さなチップで積み、それぞれ自分のタイマーで自動的に消える(`FxTicker`)。**操作も CPU の進行も待たせない**ので、CPU の待ち時間(§4)には入れない。演出が無効なら出さない。

| 種類 | きっかけ | 表示 | 長さ |
|---|---|---|---|
| `draw` | `moved`(cause=draw) | 「ドロー ×N」「相手がドロー ×N」(プレイヤーごとに1手の分をまとめる。カード名は出さない) | 1100ms |
| `step` | 状態の `turn:active:step` が変わった時(最初の表示では出さない) | 「メイン / あなた」など。ドロー・マナ・メイン・攻撃・ターン終了 | 1200ms |

ステップのうち、engine がイベントにするのはターンの開始と終了だけなので、ステップの切り替わりは状態の差分から検知する。

その他の盤面の動き(`.game.fx` の時だけ): 攻撃を宣言したクリーチャーが相手のほうへ一歩前に出る。**手番のプレイヤーの盤面の縁取り**は、情報表示なので演出が無効でも残す。

## 3. 設定(演出スキップ)

- 「⚙ 表示」の **「演出を表示する」**(対戦中に切り替え可)と、対戦設定画面の同名のチェック。同じ設定を共有する。
- 保存先: `localStorage` の `dmsim.fx`(`{"enabled": boolean}`)。対戦の設定・棋譜・自動保存には含めない(演出の有無で再現性が変わらないように)。
- 既定: 保存がなければ有効。ただし OS の「視覚効果を減らす」(`prefers-reduced-motion: reduce`)がオンなら無効。
- 「⏩ 一気に進める」中は、演出を出さず待ち時間も 0。

## 4. CPU の待ち時間(`cpuWaitMs`)

```
fast                       → 0
間隔 = 人間と対戦中 ? max(速度, 300ms) : 速度
fxEnabled                  → max(間隔, 直前の手の演出の合計)
それ以外                   → 間隔
```

演出が終わる前に、CPU が次の手で盤面を書き換えないようにするための待ちである。**待ち時間は「いつ打つか」だけを変える**。何を打つかは状態とシードだけで決まる。

## 5. 確認したこと

- `tests/ui/fx.test.tsx`: 設定の保存・既定、イベントごとの演出、隠れた情報を含まないこと、数・長さの上限、`cpuWaitMs` の表、演出あり・なしで CPU 同士の対戦の先頭 16 手が一致すること、`FxLayer` の無効化。
- `tests/ui/gameview.test.tsx`: 演出が有効なら最初のターンを見せる/保存された設定が無効ならオーバーレイも `.fx` も出ない/メニューで切ると即座に消えて保存される。
